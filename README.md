# СЛОЙ — интерактивный магазин керамики

Интерактивный прототип на React 19, TypeScript и Vite. Бренд, ассортимент и фотографии придуманы для демонстрации. Все цены в рублях. Сервер обработки заказов и платёжные интеграции отсутствуют.

## Запуск

Нужен Node.js 22.18+ и npm. Из корня проекта:

```sh
npm ci
npm run dev -- --port 5173
```

Откройте http://127.0.0.1:5173. Для остановки нажмите Ctrl+C в терминале сервера. Если порт занят, укажите другой через `--port`; Vite покажет адрес. Доступ ограничен этим компьютером.

## Что работает

- Главная с категориями, популярными предметами, подборкой и историей бренда.
- Каталог из 16 товаров: поиск по названию, цвету и описанию, категория, максимальная цена, четыре варианта сортировки и пустая выдача.
- Товар: предметное фото, увеличенная фактура, натюрморт коллекции, характеристики, размеры, количество и доступность. Размер 350 мл чашки «Утро» стоит 2 100 ₽; 250 мл — 1 800 ₽.
- Корзина: варианты не смешиваются, количества ограничены остатками, удаление и общий расчёт доставки.
- Избранное и корзина сохраняются в localStorage. Повреждённые записи отбрасываются. При запрете сохранения показывается предупреждение.
- Оформление: контакты, условный адрес, доставка, ошибки полей, обязательное подтверждение демо-режима, номер заказа и состав покупки. Повторное подтверждение защищено от дублирования.
- Мобильное меню, сворачиваемые фильтры, клавиатура и видимый фокус. Мягкие скругления, последовательное появление первого экрана, плавные меню и галерея, реакции фотографий, избранного и подтверждения. Анимации отключаются при reduced motion.
- Отдельные страницы доставки, возврата, контактов и обработки данных; неизвестные адреса показывают понятную страницу ошибки.

Прямые адреса: `/catalog`, `/product/morning`, `/cart`, `/checkout`, `/favorites`, `/about`, `/delivery`, `/contacts`, `/privacy`. Vite поддерживает прямое открытие SPA-маршрутов. После перезагрузки `/success` данные последнего демо-заказа пропадают: они хранятся только в памяти, не контакты.

## Доставка и данные

Курьер — 490 ₽, пункт выдачи — 290 ₽, условный самовывоз — бесплатно. При сумме товаров от 8 000 ₽ доставка бесплатна. Суммы считаются в целых рублях из одного источника данных.

Можно использовать вымышленные контакты. Имя, email, телефон и адрес находятся только в состоянии формы, не записываются в localStorage и не передаются по сети. В localStorage находятся только товары, варианты, количества и избранное. Аналитики, внешних шрифтов, платёжных SDK и внешних фотосервисов нет. Изображения лежат в `public/images`; фото товаров используется как фотолист с точным кадрированием каждого предмета. Ошибка изображения переключает его на подписанный резервный блок.

Реальные сертификаты, отзывы, производство, доставка и приём заказов не заявляются. Контакты и условия на информационных страницах явно обозначены как демонстрационные.

## Проверки и сборка

```sh
npm test
npm run build
```

Тесты покрывают ассортимент, варианты, некорректную сохранённую корзину, дубликаты, остатки, цены, доставку, фильтры, сортировку и валидацию формы. Сборка выполняет строгую проверку TypeScript и создаёт `dist/`.

Для локального просмотра сборки:

```sh
npm run preview -- --port 4173
```

Откройте http://127.0.0.1:4173/sloy-store/. При обновлении кода пересоберите проект. Production-сборка использует базовый путь `/sloy-store/` и hash-навигацию: например, `/sloy-store/#/product/morning`. Прямое открытие и перезагрузка страниц работают на GitHub Pages без серверных перенаправлений. В режиме разработки адреса остаются обычными: `/product/morning`.

## GitHub Pages

Сайт: https://egkodin.github.io/sloy-store/

Репозиторий: https://github.com/egkodin/sloy-store

После каждого push в `main` workflow `.github/workflows/pages.yml` устанавливает зависимости из lock-файла, запускает тесты и сборку, затем публикует `dist/` на GitHub Pages. Статус и логи доступны во вкладке Actions. Ключи и платные сервисы не требуются. Для отката сделайте `git revert` нужного коммита и отправьте результат в `main`; сайт будет пересобран. Если меняется название репозитория, обновите `base` в `vite.config.ts`.

Для клонирования и запуска:

```sh
git clone https://github.com/egkodin/sloy-store.git
cd sloy-store
npm ci
npm run dev
```

Дополнительная проверка в установленном Obscura:

```sh
# Терминал 1: npm run dev -- --port 5173
# Терминал 2:
obscura serve --port 9222 --allow-private-network
# Терминал 3:
node qa/check-browser.mjs
```

Для проверки production-адресов запустите preview вместо dev и передайте `SHOP_URL="http://127.0.0.1:4173/sloy-store/#" node qa/check-browser.mjs`. Так же можно проверить публичный сайт: `SHOP_URL="https://egkodin.github.io/sloy-store/#" node qa/check-browser.mjs`.

Скрипт проверяет покупательский путь и размеры 390, 768, 1440 px. Скриншоты сохраняются в `qa/`. QA-браузер очищает только данные своего тестового контекста. В Obscura 0.2.2 обнаружен сброс localStorage при полной навигации; скрипт распознаёт ограничение и пропускает эту проверку. Сохранение корзины и избранного отдельно проверено в настоящем браузере предпросмотра после полной перезагрузки. Результаты проверок и конкретные ограничения записаны в `qa/RESULTS.md`.

## Структура

```text
src/
  App.tsx       страницы и переиспользуемые компоненты
  data.ts       товары, варианты, остатки и формат цен
  shop.ts       фильтрация, корзина, доставка и валидация
  navigation.ts адреса страниц и локальных изображений
  main.tsx      точка входа
  styles.css    визуальная система и адаптация
public/images/  локальные фотографии
tests/          тесты бизнес-логики
qa/             повторяемая браузерная проверка и её результаты
```

Настройки сервиса и секреты не нужны. Ассортимент меняется в `src/data.ts`, тарифы доставки — в `src/shop.ts`. Для сброса демо-покупок удалите предметы в интерфейсе или очистите данные сайта в настройках браузера. Оформление заказов не изменяет внешние системы. Исходники и история изменений хранятся в Git; публикация статического сайта выполняется отдельно через GitHub Actions.
