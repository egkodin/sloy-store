# Визуальная система СЛОЙ
Молочная поверхность, винный акцент, тёмные чернила. Антиква Georgia для выразительных заголовков, системный гротеск для покупательского интерфейса. Радиусы 10 px для полей и кнопок, 12–18 px для фотографий, 22 px для больших композиций. Широкие поля, крупный натюрморт, предметная сетка, горизонтальные категории и асимметричная история. Фото — локальные сгенерированные материалы, без внешних запросов при использовании магазина.

Первый экран раскрывается последовательно: заголовок, описание, действие и фотография. Обычные реакции занимают 150–350 мс, первый экран — до 1100 мс. Карточки мягко приближают фотографию при наведении; меню, поиск и галерея появляются плавно. Избранное и успешное оформление получают короткое визуальное подтверждение. Движение не блокирует покупку, не зацикливается и отключается при prefers-reduced-motion. Эффекты реализованы в CSS без дополнительных зависимостей.
